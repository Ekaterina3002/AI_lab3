# Word-level tokenization (пословная токенизация)

## Описание
Генерация музыки с использованием пословной токенизации MIDI-файлов.  
Реализованы модели RNN, LSTM, Transformer.

## Результаты

| Модель | Финальная Loss |
|--------|---------------|
| RNN    | 0.2273    |
| LSTM   | 0.1847    |
| Transformer | 0.0077 |

**Лучшая по loss:** Transformer  
**Лучшая по генерации:** LSTM

## Запуск
1. Открыть `sample.ipynb`
2. Запустить все ячейки
